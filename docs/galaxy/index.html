Gedanken Galaxy

A searchable graph of forecasting models, from natural gas to the grocery bill, that tells you what every answer cost.

Gedanken Galaxy runs a zoo of forecasting models on five public commodity series: Henry Hub gas, European gas, nitrogen fertilizer prices, corn and food at home. Every forecast, test and result goes into a graph. You ask a question in plain English, and the Galaxy searches the graph and answers. Every answer states how many ideas it examined, and every question raises the bar for the next claim. We call this Counted Galaxy Search.

03 · KNOWN-ANSWER TEST

In markets where we planted the answer, a prompt box that does not count invents edges

Before any real question, we ran the Galaxy's search on Gedanken's simulated fertilizer-producer stock markets. In some worlds a real edge is planted, and in others there is none. Each world gets the same pool of candidate strategies, and each search rule says whether it found an edge.

04 · REAL PUBLIC DATA

On 21 years of gas, fertilizer, corn and food prices, most of what looks like an edge is not one

Monthly commodity prices are averages of daily prices, and averaging alone makes their changes partly predictable. Price indexes are smoothed too. The Galaxy measures how much predictability that alone creates by running the same zoo on simulated series where nothing is predictable, and it only credits what goes beyond it.

05 · SHADOW LOG

Live forecasts logged before the data exists, scored when it is published

Each build writes its forecasts to an append-only, hash-chained log before the target month is published. Ideas that pass become shadow strategies with frozen code. Nothing trades. The log only grows, and it cannot be backfilled, which is what makes it a track record.

06 · HOW IT WORKS

Five layers, one rule: every idea examined is counted

Model zooNine model families, from a random walk to machine learning, forecast every series at one, three and six months, using only data available at the time.
Galaxy graphSeries, models, ideas, evidence, regimes, forecasts and causal links, stored as a property graph.
Build-upA synthesis of the zoo for each target. In the known-answer test it beat every single model.
Counted ledgerA hash-chained ledger of every idea ever examined. Bars rise with it, in tiers set by the causal map.
Prompt layerTurns a question into calls to a fixed set of tools. It never computes evidence; it relays it, with the denominator.

The causal map splits the error budget before any data is seen: half for the build-up, 30% for models built on a series' causal drivers, 20% for everything else, including whatever users ask. Exploratory questions dilute only the exploratory share, so the causal build-up keeps its power however much the prompt box is used. Across the whole ledger, the chance of any false claim stays at or under 5%.

One caveat, stated plainly: the guarantee covers questions that are not chosen after seeing earlier answers. The ledger cannot stop someone from fishing, but it shows the fishing and always charges for it.

Gedanken Galaxy is an alpha release of a Vector1 research project by Brian Curry. Data: EIA (Henry Hub spot), BLS producer and consumer price indexes and IMF commodity prices via FRED. Known-answer results come from simulated markets. Nothing here is investment, trading or procurement advice. The engine, model features, causal map parameters and calibration are private; this page reads a frozen snapshot.
